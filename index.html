Asignaturas

Crea cada asignatura con sus siglas, nombre completo, código oficial (el que aparece en la guía docente, ej. 21714009) y color. Este color se usará para todas sus sesiones, igual que en la leyenda de los horarios de la ESI.

Sesiones del horario

Una sesión es un hueco día + hora + aula para una asignatura. Dentro de una misma sesión puedes añadir varios grupos (teoría, problemas, prácticas...) que se imparten juntos, tal cual aparece en los horarios oficiales. Si dos sesiones se solapan en el tiempo, la columna de ese día se ensancha automáticamente para que ambas se sigan leyendo bien.

Importar tu horario generado desde el PDF de la ESI

Cómo funciona: sube el PDF de tu horario oficial a un chat con un asistente de IA y dile qué asignatura(s) y qué grupo(s) tienes en cada una (por ejemplo: "estoy en CAL grupo A1 y B3, IG grupo A1 y C5..."). Pídele que extraiga los horarios, aulas, códigos y semanas activas de tus grupos y que te devuelva un bloque de datos en formato JSON con este esquema. Pégalo abajo y pulsa «Cargar horario» para verlo dibujado automáticamente con los mismos colores y estructura que el resto de la herramienta. 

{
  "titulo": "Grado en Ingeniería Informática",
  "curso": "1º", "semestre": "1º", "grupo": "1ºA", "anioAcademico": "2026-2027",
  "subjects": [
    { "id": "cal", "siglas": "CAL", "nombre": "Cálculo", "codigo": "21714009", "color": "#e41c1e" }
  ],
  "sessions": [
    {
      "subjectId": "cal", "day": 0, "start": "08:30", "end": "10:00", "room": "Aula D01",
      "grupos": [
        { "code": "A1", "tipo": "Clases de teoría", "weeksTotal": 16, "weeksActive": [true,true,true,false,...] }
      ]
    }
  ],
  "miniCalendar": {
    "enabled": true,
    "startDate": "2026-09-21",
    "weeksCount": 16,
    "breaks": [
      { "start": "2026-12-28", "end": "2027-01-03" }
    ],
    "holidays": [
      "2026-10-12"
    ],
    "notes": [
      "Las clases del jueves de la semana 2 se impartirán el viernes de la semana 1."
    ]
  }
}

El bloque miniCalendar es opcional: si no lo incluyes, el mini calendario simplemente no se activa (sigue apagado por defecto, tal y como esté configurado ahora mismo en la herramienta). Si lo incluyes, rellena tú mismo startDate (el lunes de la semana 1), weeksCount (semanas lectivas), breaks para periodos de vacaciones (Navidad, Semana Santa...) —esas semanas no se numeran, igual que en el horario oficial— y holidays para festivos o puentes sueltos. Tanto los días de breaks como los de holidays se pintan en rojo, igual que los fines de semana (esos se calculan solos, no hace falta indicarlos).

Importar reemplaza por completo las asignaturas y sesiones actuales. Si quieres conservar lo que tienes, exporta primero tu horario actual con el botón «Exportar .json» de la barra superior.

Mini calendario del cuatrimestre

El bloque de meses con las semanas numeradas que aparece en la esquina del horario oficial. Es independiente de las sesiones: solo marca qué semana del curso es cada fecha. Los días sin clase se pintan en rojo: los fines de semana se calculan solos; los festivos, puentes y periodos de vacaciones los añades tú abajo. Un periodo de vacaciones (Navidad, Semana Santa...) además hace que esas semanas no se numeren, igual que en el documento oficial.
