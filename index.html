Asignaturas

Crea cada asignatura con sus siglas, nombre completo, código oficial (el que aparece en la guía docente, ej. 21714009) y color. Este color se usará para todas sus sesiones, igual que en la leyenda de los horarios de la ESI.

Sesiones del horario

Una sesión es un hueco día + hora + aula para una asignatura. Dentro de una misma sesión puedes añadir varios grupos (teoría, problemas, prácticas...) que se imparten juntos, tal cual aparece en los horarios oficiales. Si dos sesiones se solapan en el tiempo, el editor las coloca automáticamente en columnas contiguas más estrechas dentro del mismo día; si una sesión va sola, ocupa todo el ancho.

Importar tu horario generado desde el PDF de la ESI

Cómo funciona: sube el PDF de tu horario oficial a un chat con un asistente de IA y dile qué asignatura(s) y qué grupo(s) tienes en cada una (por ejemplo: "estoy en CAL grupo A1 y B3, IG grupo A1 y C5..."). Pídele que extraiga los horarios, aulas, códigos y semanas activas de tus grupos y que te devuelva un bloque de datos en formato JSON con este esquema. Pégalo abajo y pulsa «Cargar horario» para verlo dibujado automáticamente con los mismos colores y estructura que el resto de la herramienta. 

{
  "titulo": "Grado en Ingeniería Informática",
  "curso": "1º", "semestre": "1º", "grupo": "1ºA", "anioAcademico": "2026-2027",
  "subjects": [
    { "id": "cal", "siglas": "CAL", "nombre": "Cálculo", "codigo": "21714009", "color": "#e41c1e" }
  ],
  "sessions": [
    {
      "subjectId": "cal", "day": 0, "start": "08:30", "end": "10:00", "room": "Aula D01",
      "grupos": [
        { "code": "A1", "tipo": "Clases de teoría", "weeksTotal": 16, "weeksActive": [true,true,true,false,...] }
      ]
    }
  ]
}
